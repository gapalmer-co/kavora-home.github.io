# KAVORA V4 — Image Sources & Usage

V4 keeps the real-photo approach from V3, but fixes the dynamic Shop catalog and product-detail URL handling.

All product cards use the exact same image URL stored in `data/catalog.json`; product-detail pages use the same canonical URL without the broken `../https://` prefix.
